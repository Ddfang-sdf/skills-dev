● 原因清楚了：

  run.py 启动 daemon 时用的是：
  [sys.executable, str(DAEMON_SCRIPT)]  → python scripts/ssh_daemon.py                                                  
  同时设置了 cwd=SCRIPT_DIR（即 scripts/ 目录），所以 ssh_daemon.py 的工作目录是 scripts/，但 Python                      的模块搜索路径（sys.path）默认包含的是脚本所在目录，而不一定是 cwd。在某些 Python 版本/环境下，scripts/ 不在 sys.path
  中，导致 from ssh_session import SSHSession 找不到模块。

  不过这不影响使用 — 脚本已自动降级为直连模式，每次命令新建 SSH
  连接，功能完全一样，只是没有长连接复用。对于偶尔操作的场景，差别不大。
