# SSH Connect Skill v2.0

**让 AI 远程操作 Linux 服务器的 Skill，重大升级**

## 老版本的问题
- 命令传参经常被 Shell 转义搞坏，AI 执行不了
- 每条命令都重新登录，慢
- 没有安全控制，`rm -rf /` 都能直接跑
- 多个 Agent 共用一个守护进程，互相打架

## 新版本做了什么
- **命令走文件不走命令行**，彻底告别转义问题
- **长连接**：daemon 常驻，一次登录多次执行，断线自动重连
- **危险命令拦截**：`rm -rf /` 直接拒绝，`rm -r` 等需你确认才放行
- **多 Agent 隔离**：每个 Agent 独立 daemon 和端口，互不干扰（Claude Code / OpenCode 随便混用）
- **跳板机穿透**：配一下 `via` 就行，AI 无感知
- **批量上传/下载**：一次传多个文件，带失败统计
- **多账号提权**：一个环境可配多个账号，AI 按需切换或 sudo 提权
- **开箱即用**：自带 exe，不用装 Python

## 使用
解压到 `skills/` 目录，告诉 AI 服务器 IP 和密码就能用。

详细说明见仓库 README：https://github.com/Ddfang-sdf/skills-dev
