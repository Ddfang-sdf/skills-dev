# SSH Connect Skill v2.0 发布公告

## 一句话概述

SSH Connect 是一个让 AI Agent 远程操作 Linux 服务器的 Claude Code Skill。v2.0 针对 v1.0 在实际使用中暴露的**传参转义、重复登录、安全失控、多 Agent 冲突**四大核心问题进行了架构级重构。

---

## v1.0 的痛点（老版本的问题）

| 问题 | 表现 |
|------|------|
| 命令传参被 Shell 破坏 | JSON 参数在 PowerShell / Git Bash / CMD 下被不同规则转义，命令到不了 Python 层，AI 被迫把命令写进临时文件规避 |
| 每条命令重新登录 | 无长连接，频繁登录耗时且日志噪音大 |
| 无安全控制 | `rm -rf /` 可以直接执行，零拦截 |
| sudo 提权脆弱 | invoke_shell 轮询等待密码提示，经常卡死 |
| 结果截断后 AI 乱试 | stdout 被截断后，AI 不读完整结果就换命令重试 |
| 多 Agent 互相打架 | 两个 Agent 抢同一个 daemon 端口，token 冲突不断 |

---

## v2.0 核心能力

### 1. 文件桥接 — 彻底消灭传参转义

命令不再走命令行参数，AI 用 Write 工具写 `inbox/{task_id}.json`，脚本扫描执行，结果写 `outbox/result_{task_id}.json`。全程不经 Shell，零转义风险。副作用收益：用户在 Agent 界面可直接看到要执行的命令。

### 2. daemon 长连接池

后台 daemon 常驻，同一服务器复用一条 SSH 连接；心跳保活（60s）、空闲回收（300s）、断线自动重连。多条命令一次登录。

### 3. 危险命令三级硬拦截

- **BLOCK**（`rm -rf /`、`dd of=/dev/sdX`、fork 炸弹）：始终拒绝，无法绕过
- **WARN**（`rm -r`、`sed -i`、`kill -9`、`shutdown`、`curl|bash`）：默认拒绝，用户当次确认后 `force=true` 放行
- **ALLOW**：直接放行

脚本是最后一道机械门禁，AI 只负责传话，不决策。

### 4. 多 Agent 完全隔离

每个 Skill 安装实例自动分配独立 daemon 端口（`daemon.port` 文件记录），Claude Code / OpenCode / 多个实例各自运行各自的 daemon、各自的环境配置、各自的 inbox/outbox，互不干扰。升级时 daemon 自清理旧进程，无需手动杀进程。

### 5. 跳板机透明穿透

`via` 字段声明跳板关系，direct-tcpip 隧道在 SSH 传输层打通，AI 只写目标 IP，跳板过程完全无感知。跳板机和目标机各自保活一条长连接。

### 6. 多凭证与提权

- 一个环境可配置多组账号（admin / root / deploy），`as` 字段按需切换
- 命令先以当前用户执行，权限不足时 AI 决策：设 `escalate: true` 走 `sudo -S` 管道提权，或 `as` 换高权限凭证
- 敏感操作（如修改 sshd_config）**明令禁止**，脚本层不提供此能力

### 7. 批量文件传输

`upload` / `download` 统一数组格式（单文件也用数组），一次任务传多个文件，返回 `total/failed/errors` 统计与逐项失败原因。敏感远端路径（/etc/shadow、~/.ssh 密钥、系统目录）同样受 WARN 拦截。

### 8. 环境配置脚本化管理

AI 不再直接写 env_config.json，通过 `env` 操作（add / update / remove / list / credential_add / credential_remove）由脚本校验后写入。新增环境后 daemon **配置热更新**，无需重启即可连接。

### 9. 可靠性设计

- daemon 执行失败自动降级为直连模式，业务不中断，stderr 明确提示
- `known_hosts` accept-new 机制：首次连接记录指纹，密钥变更拒绝连接（防 MITM）
- 超时错误码结构化（COMMAND_TIMEOUT / AUTH_FAILED / HOSTKEY_CHANGED / UNREACHABLE），AI 按表处置

### 10. 开箱即用 exe

PyInstaller 打包 `ssh-run.exe` / `ssh-daemon.exe`，用户无需安装 Python 和 paramiko，解压即用。

## 升级说明

老版本直接删除，将本目录拖入 `.claude/skills/` 即可。首次使用通过对话告知 AI 服务器凭证，AI 自动录入。多 Agent 用户无需任何额外配置，端口自动隔离。

**注意**：v2.0 的任务文件协议（inbox JSON 字段）与 v1.0 的 `--json` 命令行参数不兼容，但仍保留 `--json` 兼容模式作为降级入口。
