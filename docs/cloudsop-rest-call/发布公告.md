# CloudSOP REST Call Skill

**让 AI 自己调接口排查问题/验证需求，不用你手把手教**

## 它是干嘛的

以前：你让 AI 帮你定位问题，AI 说"建议你调一下 xx 接口看看返回"，然后你自己开 Postman 调、截图给 AI 分析。

现在：AI 自己调接口，直接把分析结论给你。

## 举个例子

```
你：帮我看下事件统计接口返回好像不对
AI：（自己调接口）接口数据正常，42 条。页面显示 0 是前端过滤条件问题。

你：需求做完了帮我测一下
AI：（自己调接口验证）数据已正确入库，详情页也正常。

你：服务好像起不来
AI：（自己调 healthcheck）服务 503 还没起来，建议先看日志。
```

## 怎么用

1. 把 `cloudsop-rest-call` 目录放到 skills 目录
2. 告诉 AI 服务器 IP 和登录账号（默认 admin/Changeme_123）
3. 正常问问题就行，AI 会自己判断要不要调接口

不需要会说"帮我调 xx 接口"，正常描述问题就好。

## 两个模式

- **ER（31943）**：对外接口，AI 本机直连
- **IR（32018）**：内部接口，通过 ssh-connect 到管理节点调用（需要装好 ssh-connect skill）
